# tarea1-prog1

* Tarea realizada por Mayki Monroy que es una aplicación de consola en Python con conexión a base de datos PostgreSQL.
* La temática es sobre administrar alumnos desde un menú. Permitiendo el poder: agregar, modificar, listar, eliminar y salir.
* Solamente usa Python puro y la librería psycopg2.
